## 🧑‍💻 About Me

I'm a DevOps Engineer who treats infrastructure like code, downtime like a personal insult, and YAML indentation like a sacred ritual. I build cloud-native systems that are scalable, observable, and boring to operate — _because boring infrastructure is the best infrastructure._

- 🏗️ **Design** highly available, fault-tolerant AWS architectures using well-architected principles
- 🤖 **Automate** everything that breathes — provisioning, deployment, scaling, recovery
- 🚢 **Ship** containerized workloads on **ECS**, **EKS**, and bare metal when nostalgia hits
- 📡 **Observe** systems with metrics, logs, and traces so I find issues before Slack does
- 🔐 **Secure** pipelines and infrastructure with IAM least-privilege, Secrets Manager, and a healthy dose of paranoia
- 💎 **Run** production **Ruby on Rails** workloads backed by **Redis** & **PostgreSQL**
- 📝 **Document** like the next on-call engineer is a stranger with a baseball bat who knows where I live

> 🤫 _Yes, I've fixed production at 3 AM. No, I don't want to talk about it._
